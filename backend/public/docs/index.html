Developer Documentation

Welcome to the Slotcore developer documentation. Slotcore provides the infrastructure you need to build powerful scheduling and booking experiences with ease.

Quick Start

To get started, you'll need an API key from your Slotcore dashboard. We provide both Public (pk_...) and Secret (sk_...) keys. All endpoints are prefixed with /api/v1. 

# Example: Using the SDK in a Node.js project
npm install @slotcore/sdk  # Coming soon!

Authentication

Authenticate your requests by including your API key in the Authorization header as a Bearer token or using the X-API-KEY header. 

fetch('https://api.slotcore.com/api/v1/availability', {
  headers: {
    'Authorization': 'Bearer YOUR_API_KEY'
  }
});

SDK Reference

The Slotcore JavaScript SDK simplifies interacting with our API from both the browser and Node.js.

Setup

const Slotcore = require('slotcore-sdk');
const slotcore = new Slotcore('sk_test_...');

// For multi-tenant applications
const slotcore = new Slotcore('pk_test_...', {
  tenantSlug: 'my-business'
});

Availability

Query available slots for your services.

const slots = await slotcore.availability.list({
  service_id: 'uuid',
  date: '2024-03-10'
});

Bookings

Manage appointments and reservations.

// Create a booking
const booking = await slotcore.bookings.create({
  service_id: 'uuid',
  start_time: '2024-03-10T10:00:00Z',
  customer: {
    name: 'John Doe',
    email: 'john@example.com'
  }
});

// Cancel a booking
await slotcore.bookings.cancel('booking_id');

Services

Retrieve information about offered services.

const services = await slotcore.services.list();

Customers

Manage customer data (requires Secret Key).

const customers = await slotcore.customers.list();

API V1 Reference

Comprehensive list of endpoints available in the Platform V1.

Auth (API Keys)

Method Endpoint Description
GET /auth/keys List organization API keys
POST /auth/keys Create a new API key
DELETE /auth/keys/:id Revoke an API key
PATCH /auth/keys/:id/toggle Activate/Deactivate key

Orgs

Method Endpoint Description
GET /orgs/me Get current organization profile
PATCH /orgs/me Update organization settings

Services

Method Endpoint Description
GET /services List all services
GET /services/:id Get service details
POST /services Create a new service
PATCH /services/:id Update a service
DELETE /services/:id Delete a service

Staff

Method Endpoint Description
GET /staff List all staff members
GET /staff/:id Get staff details
GET /staff/:id/availability Get staff specific schedules

Availability

Method Endpoint Description
GET /availability Query slots (Slot Engine)

Bookings

Method Endpoint Description
GET /bookings List bookings with filters
POST /bookings Create a new booking
GET /bookings/:id Get booking details
PATCH /bookings/:id Update booking metadata/notes
PATCH /bookings/:id/cancel Cancel a booking

Customers

Method Endpoint Description
GET /customers List organization customers
GET /customers/:id Get customer profile
POST /customers Create or update a customer

Webhooks

Method Endpoint Description
GET /webhooks List configured webhooks
POST /webhooks Register a new webhook
DELETE /webhooks/:id Delete a webhook
GET /webhooks/events List supported event types
GET /webhooks/:id/events List delivery history

Locations

Method Endpoint Description
GET /locations List business locations
GET /locations/:id Get location details
